# Exercise reference images

The bundled exercise demonstrations are sourced from [Free Exercise DB at commit `f00c92c`](https://github.com/yuhonas/free-exercise-db/tree/f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5), released under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5/LICENSE.md).

Images are stored locally so exercise info works offline. Catalog variations without an exact source-dataset match use a visually similar movement; the info modal identifies the demonstrated exercise. Images are reference demonstrations, not medical or coaching advice.
